Printable Web

Accessible HTML and CSS as an open alternative to the PDF. Semantic web documents read natively with screen readers, adapt to every screen width, and print cleanly onto standard 8.5×11" letter paper without proprietary software subscriptions.

01 / PurposeExecutive summary and purpose

This reference architecture establishes the technical thesis, civil-rights grounding, and design patterns for three connected priorities at Lujan Creative Agency LLC: ending proprietary document lock-in, meeting ADA Title II/III and Section 508 mandates natively, and publishing resilient open-web documents.

Civil rights mandates vs. vendor lock-in

Federal accessibility mandates (ADA Title II/III and Section 508) require compliance with WCAG 2.1 AA and open ISO standards—not recurring software taxes paid to remediate untagged fixed-layout files.

ADA Title III · WCAG 2.1 AA

The self-demonstrating document

This page is its own proof of concept. Written in semantic HTML with pica-grid proportions and a dedicated print stylesheet, it navigates cleanly by keyboard or screen reader and prints as a crisp letter-size brief.

Zero PDF Middleware

02 / The Core ThesisWhy fixed print artifacts fail the modern web

The Portable Document Format is a 30-year-old print emulation format treated as a web default. Relying on static 8.5×11" binary blobs introduces avoidable friction for readers, mobile users, and assistive technology.

Dimension The Printable Web (HTML + CSS) Legacy Untagged / Remediated PDF
Screen Reader Tree Native DOM landmarks (<header>, <main>, <section>, <table>) work out of the box. Requires manual tag-tree reconstruction in proprietary desktop software after export.
Mobile Viewport Reflows fluidly from 320px phones to 75pc desktop monitors and respects user zoom. Forces horizontal pinching and zooming across rigid two-column print blocks.
Physical Print Output @media print formats letter-size margins, page breaks, and full URL citations on demand. Locked to a single page size; broken links and dark backgrounds waste toner.
Ownership & Cost 100% open web standards, version-controlled in Git, zero per-seat licensing. Recurring subscription overhead and fragile binary files that rot outside version control.

03 / ArchitectureFour pillars of the Printable Web

Instead of forcing audiences to download non-responsive attachments, publish live HTML pages engineered for both screen and paper.

Semantic landmarks

Strict heading hierarchy, explicit table headers (scope="col"), and ARIA live regions provide immediate screen-reader clarity.

01 / DOM

Fluid pica grid

Quarter-pica spacing steps (1pc = 16px) and 44×44px minimum touch targets keep interfaces comfortable across every device.

02 / Layout

Print media queries

@page { size: letter; margin: 0.55in; } strips chrome, enforces high-contrast ink on paper, and prevents awkward mid-card breaks.

03 / @media print

Code-driven identity

Living design tokens (--lj-mag, --lj-pink, Geist Pixel, Geist Mono) replace static PDF brand books with reusable code.
