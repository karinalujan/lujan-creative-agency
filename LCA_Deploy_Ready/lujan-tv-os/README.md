# Lujan TV OS

A customizable D-pad launcher for Fire TV, built by **Lujan Creative Agency LLC** ([lujan.design](https://www.lujan.design/)). It replaces the stock home screen with a high-contrast interface engineered for the remote's directional pad, styled in the `lujan.design` pixel-and-mono system (`Geist Pixel` + `Geist Mono`, `#111` carbon, `#DD0070` cochineal magenta, `#FC8DC1` agave pink) with an ambient sound layer generated by the Web Audio API.

## Install on a Fire TV

1. On the TV: **Settings > My Fire TV > Developer options**, turn on **ADB debugging** and **Apps from unknown sources**.
2. Find the TV's IP: **Settings > My Fire TV > About > Network**.
3. From your computer:
   ```bash
   adb connect <TV_IP>:5555
   adb install lujan-tv-os.apk
   ```
   Release APKs are published on the **Releases** page of this repository.

## Customize & Live Preview

The launcher interface lives in `src/index.html` as self-contained, zero-dependency HTML, CSS, and JavaScript. Edit `src/index.html`, then preview directly on your Fire TV over LAN without rebuilding the APK:

```bash
./scripts/deploy.sh <TV_IP>
```
