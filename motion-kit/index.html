Adding them in Webflow

  1. Paste the variables once. Site settings → Custom code → Head code. Leave the two font lines commented out and the effects use the fonts already on your page.

  2. Drop in a Code Embed where the effect belongs and paste its snippet. For the pixel field, put the embed first inside the hero section, set that section to position: relative and give the hero content z-index: 1.

  3. Publish to test. The Designer shows markup but doesn't run scripts, so most effects only move on the staging or live site.
